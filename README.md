# QuickPoll

Tap-first polls for clients. Build a poll in a minute, send a link, and answers land in your Google Sheet automatically, with an email for each one.

- **No sign-up** for respondents, no server: static pages (GitHub Pages) + Google Apps Script.
- One question per screen, big buttons, auto-advance. Works great on phones.
- Question types: single / multiple choice, yes/no, 1–5 or 1–10 scale, image choice, short text, plus an optional comment on any question.
- Builder with live phone preview, a text mode (write the whole poll as a list), templates, and drafts saved in your browser.
