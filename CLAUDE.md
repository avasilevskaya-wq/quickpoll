# Инструкции для Claude

- Сначала прочитай **PROJECT.md**: там цель, принципы, архитектура, текущее состояние и журнал решений.
- Перед любыми дизайн-решениями прочитай **DESIGN-PRINCIPLES.md** (библиотека дизайн-правил) и проверь результат по нему. Новые правила, которые называет владелец, добавляй туда по шаблону.
- Общайся по-русски. Интерфейс продукта — на английском.
- Владелец проекта учится Git и GitHub. Объясняй простыми словами, давай **по одному шагу за раз** и жди подтверждения.
- Не делай коммиты и push сам: владелец делает Commit → Sync в VS Code. Скажи, какую подпись к коммиту написать.
- Если меняешь `apps-script/Code.gs`, напомни: код нужно вставить в Apps Script и выпустить **новую версию** развертывания.
- После изменений обновляй PROJECT.md (журнал решений, бэклог).
