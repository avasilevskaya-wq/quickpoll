# PROJECT.md — QuickPoll

> Контекст проекта для ИИ-ассистентов (Claude, Claude Code и др.) и для людей.
> Читай этот файл перед любыми изменениями. Принятые решения дописывай в «Журнал решений».

## Зачем

Быстрые опросы для заказчиков и стейкхолдеров. Владелец (менеджер проекта) за минуту собирает опрос и отправляет ссылку. Заказчик отвечает в несколько кликов с телефона или компьютера, а ответы сами попадают в Google-таблицу, и владельцу приходит письмо.

Аналог Google Forms, но заметно быстрее и проще для обеих сторон.

## Кто пользуется

- **Владелец опроса** — менеджер проекта, по-русски пишет быстрее. Интерфейс конструктора на английском, но с минимумом текста.
- **Респондент** — заказчик или стейкхолдер, часто иностранный (интерфейс опроса **только на английском**). Может вообще не пользоваться ИИ-сервисами. Нельзя требовать регистрацию, аккаунты или установку чего-либо.

## Принципы (не нарушать)

1. **Минимум текста, максимум кликов.** Один вопрос на экран, большие кнопки. Автоперехода нет: выбор только выделяет вариант, чтобы можно было спокойно добавить комментарий.
2. **Ноль трения для респондента.** Без регистрации, без привязки к Claude или другим сервисам. Ответ в один тап.
3. **Ноль ручной работы для владельца.** Ответы сами падают в таблицу, никакого копирования.
4. **Без своего сервера.** Статика на GitHub Pages и Google Apps Script как приёмник. Бесплатно.
5. **Mobile-first**, светлая и тёмная тема, доступность (клавиатура, aria, контраст).
6. Без зависимостей и сборки: чистые HTML, CSS и JS. Деплой — просто загрузить файлы.
7. **Минимализм в визуале.** Не перебарщивать с объёмом и эффектами: яркое свечение — только у одного элемента на экране, вспомогательные элементы лёгкие и плоские.

## Архитектура

```
Конструктор (index.html) ──► ссылка …/s/#<опрос, сжатый в URL>
                                   │
Респондент открывает /s/ ──► отвечает ──► POST JSON ──► Google Apps Script (Web App)
                                                            ├─► вкладка Google-таблицы (строка на ответ)
                                                            └─► письмо владельцу
```

- **Опрос хранится в самой ссылке**: JSON → `deflate-raw` (CompressionStream) → base64url в `#hash`. Префикс `z` значит сжатие, `j` — простой JSON (fallback). Базы опросов нет.
- **Черновики** живут в `localStorage` браузера владельца (`qp_drafts`, `qp_current`). На другом устройстве опрос открывается через «My polls → Open a poll from its link».
- **Адрес приёмника** (`/exec` URL Apps Script) берётся из `config.js` или из настроек конструктора (`qp_endpoint` в localStorage). Если адрес из настроек отличается от `config.js`, он встраивается в ссылку (`e`).
- **Отправка**: `fetch` POST с `text/plain` (без CORS-preflight). Если ответ нечитаем, идёт повтор с `no-cors`. Дубликаты отсекаются по `subId`.
- **Навигация респондента**: внизу «← Previous» и справа одна кнопка: «Skip» (вторичная), пока нет ответа, и «Next →» (основная), когда ответ есть. Обязательный вопрос помечен «Required» с пояснением, что его можно пропустить сейчас. На экране проверки пропущенные обязательные вопросы подсвечены, «Send» неактивна, кнопка «Answer now →» ведёт к первому из них. После ответа кнопка ведёт «Back to review».
- **Картинки**: строка картинки = превью · подпись · поле «Paste image (Ctrl+V) or link» (вставка картинки грузит её именно в эту строку) · иконка ⬆ (окно с зоной drag & drop и ссылкой «open a folder on your computer») · ✕. Перетаскивание на карточку тоже работает. Раскладка картинок (`y`): Auto (по умолчанию: широкие картинки во всю ширину, иначе сетка или ряд из трёх), Grid, Row, Full width; в текстовом формате `[images, grid|row|full]`. Картинки показываются целиком (`object-fit: contain`), лупа открывает полноэкранную галерею: стрелки ‹ ›, клавиши ← →, свайп, счётчик «2 / 3», кнопка «Choose this» (Enter) для картинки на экране. Крестик у последней строки картинки или варианта очищает поля, а не удаляет строку. Повторный клик по выбранному варианту (любого типа) снимает выбор; в галерее выбранная картинка обведена и с галочкой, кнопка становится «Unselect» (secondary) и снимает выбор, не закрывая просмотр. Конструктор уменьшает картинку до 1600px и отправляет её в Apps Script (`action: "upload"` + `key`). Скрипт сохраняет файл в папку Drive «QuickPoll images», открывает доступ по ссылке и возвращает `https://lh3.googleusercontent.com/d/<id>` (запасной вариант — `drive.google.com/thumbnail`). Ключ загрузки (`UPLOAD_KEY`) скрипт создаёт сам и показывает в журнале после запуска `authorize`. Его вставляют в ⚙ Settings конструктора (хранится в localStorage, в репозиторий не попадает). Функция `cleanupOldImages` отправляет в корзину картинки старше 30 дней.
- **Таблица**: каждый опрос — своя вкладка `«<title> · <id>»`. Колонки: Submitted | Name | Submission ID (скрыта) | `N. Вопрос` | `N. Вопрос — comment`. Новые колонки создаются по мере необходимости. Защита от формул-инъекций (`'` перед `= + - @`).

## Схема опроса (короткие ключи, чтобы ссылки были короче)

```js
{ v:1, id:"ab3k9x", t:"Title", d:"Intro", n:1 /*ask name*/, e:"https://…/exec" /*optional*/,
  q:[{ k:"s"|"m"|"y"|"r"|"i"|"x", t:"Question", h:"Hint", r:1 /*required*/, c:1 /*allow comment*/,
       o:["A","B"] /*options: s, m, i*/, i:["https://img…"] /*image urls: i*/, s:5|10, l:["Low","High"] /*scale*/,
       w:["Button text","https://…"] /*link button, any type*/, m:["https://img…"] /*pictures to look at, any type*/ }] }
```

Типы: `s` один вариант · `m` несколько · `y` да/нет · `r` шкала 1–5/1–10 · `i` выбор картинки · `x` короткий текст.

`id` опроса не меняется при редактировании, поэтому ответы на старую и новую ссылку идут в одну вкладку. «Copy» в My polls создаёт новый `id`.

## Текстовый формат (вкладка Text, шаблоны)

```
# Title
> Intro
[ask name]

Question                      ← строки "- …" ниже = варианты (single)
- A
- B
Question [multi | yes/no | 1-5: Low | High | 1-10 | images | text]
Question [yes/no, comment, optional]
? Hint line
- Label | https://image.png   ← для [images]
link: Button text | https://…  ← кнопка-ссылка под пояснением (любой тип)
image: https://image.png       ← картинка к вопросу, просто посмотреть (любой тип, по строке на картинку)
```

## Как проверять

- Локально: `python3 -m http.server` в корне, открыть `http://localhost:8000/`.
- Пройти: создать опрос → Get link → открыть → ответить на телефонной ширине (375px) → проверить payload.
- Apps Script проверяется только в Google (после изменений нужна **Новая версия** развертывания).
